# W=1024 真实配置对照（填补 AAR §三 的缺口）

> 产生方式：`pg_lab/analyze_w1024.py` + `pg_lab/train.py --seq-len 1024 --batch-seqs 8`
> 数据：`pg_lab/analysis_w1024/analysis_seed{1337,42,2026}.json`、`summary_w1024.json`
> 原始输出：`evidence/w1024_config_check.txt`

## 为什么补这一组

原实验的训练窗口是 512，只测了「评测窗口 1024（> 训练窗口）」的负结果，
没有测**官方真实配置**「训练窗口 1024 + 评测窗口 1024」。
v3 补上：三个 seed，与 W=512 实验**完全相同的 token 预算**（1024×8 = 512×16 = 8192 tokens/step，
1200 步），唯一变量就是训练窗口大小。

## 结果（n=3 seed，配对计算）

| 代价倍数 | stride | ΔBPB 均值 | 配对 std | 占最大收益比 |
|---|---|---|---|---|
| 1.00× | 1024 | 0.000000 | 0.000000 | 0% |
| 1.33× | 768 | −0.017739 | 0.000430 | 95.6% |
| **2.00×** | **512** | **−0.018548** | **0.000459** | **100%（最优）** |
| 2.67× | 384 | −0.018313 | 0.000496 | 98.7% |
| 4.00× | 256 | −0.017606 | 0.000540 | 94.9% |
| 8.00× | 128 | −0.016015 | 0.000723 | 86.3% |
| 16.00× | 64 | −0.013653 | 0.001121 | 73.6% |

- 朴素基线 BPB 均值 **2.07601**
- **最优档就是 2×**（stride=512）
- **2× 比 16× 好 0.004894 BPB**（配对 std 0.000674，3/3 seed 符号一致）
- 1.33× 就能拿到 95.6% 的最大收益

## 与 W=512 实验的对比

| | W=512（原实验） | W=1024（真实配置，本次） |
|---|---|---|
| 最优代价倍数 | 2.67×（约等于 2× 档） | **2.00×** |
| 2× vs 16× 之差 | 0.00154 BPB | **0.004894 BPB** |
| 越过拐点是否变差 | 是 | **是，且更明显** |

**结论**：真实配置下结论不变，且「16× 买贵了」这个效应比小窗口时**更强**。
这解掉了原 AAR §三 里唯一一个"可补但没补"的缺口。

## 方法学自检（W=1024）

ρ 重建 vs 逐字节金标准直接评测，最大误差 **2.46×10⁻³ BPB**（与 W=512 时的 2.09×10⁻³ 同一量级），
即 ρ 解析捷径在 W=1024 上同样可靠。
